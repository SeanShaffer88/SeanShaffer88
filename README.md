# Sean Shaffer

I build free, local-first Windows tools, developer utilities, knowledge bases, and World of Warcraft addons. My work favors practical software, explicit data handling, offline workflows, and honest validation over ads, accounts, telemetry, or subscriptions.

## What I’m building

- **Useful native tools** for Windows — desktop apps, installers, utilities, and system care software.
- **Open developer infrastructure** — build evidence, release checks, verification tools, documentation, and reusable libraries.
- **WoW Forever addons** — focused, accessible UI improvements backed by small Lua libraries and predictable in-game behavior.
- **Offline-first resources** — searchable catalogs and knowledge bases that remain useful without a cloud service.
- **Evidence-based revivals** — preserving useful open-source projects, documenting provenance, and separating maintained work from upstream ownership.

## How I work

- Keep core workflows **local and explicit**.
- Prefer **native software**, useful defaults, portability, and clear recovery paths.
- Validate with build evidence, CI, packaging checks, hashes, and honest compatibility notes.
- Preserve upstream attribution and licenses when reviving existing projects.
- Keep releases **free**; avoid ads, selling data, telemetry, and paywalls on core functionality.

For bugs or contributions, use the issue tracker in the relevant project and include Windows version, build details, and reproduction steps where applicable.
