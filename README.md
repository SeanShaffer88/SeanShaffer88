## How I approach the work

- Keep core workflows local and make changes explicit.
- Use existing stacks where they fit: Rust, C++, C#, and Python.
- Preserve upstream credit and licenses when reviving useful projects.
- Describe validation and compatibility honestly, including unfinished release gates.
- All software is completely free; optional donations never unlock anything, and there are no ads, in-app purchases, or data sales.

For bugs, ideas, or contributions, use the relevant project's issues. A clear reproduction, Windows version, and build details help me investigate.
