# Sean Shaffer

I build Windows desktop tools and developer utilities, with a focus on local workflows, understandable changes, and useful diagnostics.

My projects range from desktop applications to focused C++ library revivals. I care about showing what works today, documenting the limits, and making the next step easy to find.

## Featured projects

| Project | What you can explore | Status |
| --- | --- | --- |
| **[AppTrail](https://github.com/SeanShaffer88/AppTrail)** | Capture application or project folders, compare snapshots, inspect source/config diffs, and export offline HTML reports. Python desktop app with a Windows x64 download. | Released; Windows 11 x64 tested |
| **[win-pipe revival](https://github.com/SeanShaffer88/win-pipe-revival)** | A single-header C++17 local IPC library with bounded messages, cancellable pipe I/O, regression tests, and a real multi-process logging example. Derived from goodtrailer/win-pipe; ISC licensed. | Released 0.2.0; desktop x86/x64 scope |
| **[Meridian](https://github.com/SeanShaffer88/Meridian)** | An offline-first Windows 11 file manager with dual-pane workspaces, Folder DNA summaries, and reviewed batch-copy workflows. Built with C#, .NET, and WinUI 3. | Early development preview |

## Also in development

- **[SetupSweep](https://github.com/SeanShaffer88/SetupSweep)** — a Rust Windows toolkit for installation evidence, reviewed system changes, and developer-environment diagnostics. Local milestones can be ahead of published source and downloads; see its README for scope.
- **[CursorCabinet](https://github.com/SeanShaffer88/CursorCabinet)** — a native C++ cursor browser with previews, per-user application, and recovery of the preceding scheme. Native releases are previews.

## How I approach the work

- Keep core workflows local and make changes explicit.
- Use existing stacks where they fit: Rust, C++, C#, and Python.
- Preserve upstream credit and licenses when reviving useful projects.
- Describe validation and compatibility honestly, including unfinished release gates.
